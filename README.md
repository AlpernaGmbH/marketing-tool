# marketing-tools (tools.alperna.ch)

Marketing-Werkzeuge für Schweizer KMU und Vereine. Betrieben von der Alperna GmbH.

Vertrag und Arbeitsweise: `CLAUDE.md`. Stand und offene Punkte: `STATUS.md`.

```bash
npm install
cp .env.example .env.local   # oder: vercel env pull .env.local
npm run dev
npm run check                # typecheck, test, content-check, build
```
