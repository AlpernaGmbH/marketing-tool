## Warum das wichtig ist
Ein QR-Code bringt Leute vom Papier auf deine Website, zu deiner Google-Bewertung oder in deinen WhatsApp-Chat, ohne Abtippen. Das QR-Code-Set macht aus bis zu sechs Zielen Codes mit Beschriftung, druckfertig für Flyer, Aufkleber und Schaufenster in Gossau, Herisau oder Frauenfeld.

- **Jeder Code hat ein Ziel:** Website, Instagram, LinkedIn, WhatsApp, Google-Bewertung oder Speisekarte, mit einem Satz darunter.
- **Druckfertig:** Der Druckbogen A4 zeigt jeden Code 50 mm breit mit Schnittmarken, so wie die Druckerei in Wil ihn braucht.
- **Dateien für alles andere:** SVG für Grafikprogramme und Plotter, PNG für Word und Canva.
- **Vorschläge statt Tipparbeit:** Die Website aus deinem Firmenprofil ist das erste Ziel, die Nummer aus dem WhatsApp-Link das zweite.
- **Nichts Verstecktes:** Im Code steht nur die Adresse, keine Umleitung über einen fremden Dienst.

=> Gleich darunter: wohin welcher Code gehört, vom Fahrzeug bis zur Rechnung.

## So nutzt du das Ergebnis
1. **Ein Code je Ort.** Fahrzeug und Baustellentafel bekommen die Website, der Tresen die Google-Bewertung, die Rechnung WhatsApp.
2. **Druckbogen an die Druckerei.** Das PDF hat Schnittmarken; für Aufkleber reicht ein Laserdrucker mit Klebefolie.
3. **Dateien in deine Vorlagen.** Das SVG in Flyer und Plakat, das PNG in Word, Canva oder die Präsentation.
4. **Vor dem Druck testen.** Scanne jeden Code mit zwei Handys, bei Tageslicht und bei Lampenlicht.
5. **Ziele im Blick behalten.** Zieht deine Website um, brauchst du einen neuen Code und neue Aufkleber.

=> Gleich darunter: der Fehler, mit dem ein Code auf jedem Flyer unlesbar wird.

## Häufige Fehler
- **Den Code zu klein drucken.** Unter 2 cm Kantenlänge scannen viele Handys nicht mehr (Richtwert von Alperna, keine Statistik), also plane den Platz vor dem Layout.
- **Den hellen Rand wegschneiden.** Ohne die Ruhezone von vier Modulen rundum (ISO/IEC 18004) findet die Kamera den Code nicht, also lass den Rand stehen.
- **Hell auf dunkel oder auf ein Foto legen.** Das Handy braucht dunkle Module auf hellem Grund, also setz den Code auf Weiss.
- **Die Adresse mit Tracking-Anhängseln verlängern.** Je länger die Adresse, desto dichter der Code, also nimm die kurze Form.

=> Gleich darunter: das fertige Set der Malerei Keller mit vier Codes.

## Häufige Fragen
### Wie gross muss ein QR-Code sein?
Mindestens 2 cm Kantenlänge auf Flyern und Aufklebern (Richtwert von Alperna, keine Statistik). Je weiter weg die Leute stehen, desto grösser, etwa im Schaufenster oder am Fahrzeug. Der Druckbogen gibt jedem Code 50 mm.

### Funktioniert das ohne Internet?
Der Code selbst braucht kein Netz, er enthält nur die Adresse. Das Handy, das ihn scannt, braucht Netz, um die Seite zu öffnen. In einer Werkstatt ohne Empfang hilft darum kein Code.

### Kann ich das Ziel später ändern?
Nein. Die Codes sind statisch: Die Adresse steht direkt im Code, ohne Umleitung. Zieht deine Website um, brauchst du einen neuen Code. Dafür funktioniert er ohne Abo und ohne Fremdanbieter, solange die Adresse besteht.

### Welche Ziele gehen?
Website, Instagram, LinkedIn, WhatsApp, Google-Bewertung, Speisekarte oder PDF und jeder andere Link mit http oder https. Aus einem Instagram-Handle wird die Profiladresse, aus einer Schweizer Nummer ein wa.me-Link. Doppelte Ziele weist das Werkzeug ab.

### Brauche ich ein Konto?
Nein. Du gibst vor dem Ergebnis deine E-Mail-Adresse an. Das Häkchen für Kontakt durch Alperna ist freiwillig. Danach fragt ein Jahr lang kein Werkzeug erneut, und Druckbogen und ZIP sind sofort frei.

### Was bekommt Alperna, und was bleibt im Browser?
Mit dem Ergebnis gehen deine Ziele mit Adresse und Beschriftung, der Firmenname und deine E-Mail-Adresse an Alperna. Codes, PDF und ZIP entstehen in deinem Browser; dein Firmenprofil bleibt dort.
